# Extract Google Meet Captions

## Overview

The `extract-captions.js` script is designed to extract caption texts generated by the STT service from a Google Meet meeting page. It identifies specific HTML elements containing the names and corresponding caption texts of participants and combines them into a readable format.

## Functionality

- **Extracts Names**: The script locates the `span` elements with the class `NWpY1d` to extract the names of the participants.
- **Extracts Caption Texts**: It finds the `div` elements with the class `bh44bd VbkSUe` to extract the caption texts.
- **Combines Name and Text**: The script combines the extracted name and caption text into a single string in the format "Name: Text".

## Usage

Paste and run the code in the browser's console on a Google Meet meeting page. Call the `extractCaptions` function to extract the caption texts.

## Example

```javascript
// Example usage
const extractedCaptions = extractCaptions();
console.log(extractedCaptions);
```
